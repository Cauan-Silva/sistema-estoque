# 📦 Sistema de Gestão de Estoque

Sistema desenvolvido em Python para gerenciamento e controle de estoque.

## 🎯 Objetivo

Desenvolver uma aplicação capaz de controlar produtos, categorias, entradas e saídas de estoque.

O projeto também tem como objetivo aplicar conceitos de desenvolvimento backend, banco de dados, APIs e análise de dados.

## 🚀 Tecnologias

- Python
- FastAPI
- PostgreSQL
- Git e GitHub
